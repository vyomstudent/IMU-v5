============================================================
CHANGE 2 — ADD BluetoothLE1.BytesReceived
============================================================

ADD this NEW event:

when BluetoothLE1.BytesReceived serviceUuid characteristicUuid byteValues

  if serviceUuid = SERVICE_UUID
     AND characteristicUuid = ANALYTICS_UUID
  then

    call WebViewer1.EvaluateJavaScript
      script =
        join(
          "window.VSPIMU.receiveEspAnalyticsCsv(\"",
          list to csv row byteValues,
          "\");"
        )

The generated JavaScript must have this form:

window.VSPIMU.receiveEspAnalyticsCsv("0,73,5,1,...");

For a final summary there are exactly 168 byte values.
For each IC/FC event packet there are exactly 144 byte values.

DO NOT decode the 168-byte or 144-byte packet manually in App Inventor.
The JavaScript performs the binary decoding.

IMPORTANT:
  Use LIST TO CSV ROW, not LIST TO CSV TABLE.
  The byte values must remain decimal byte values 0–255.

CHANGE 4 — MODIFY WebViewer1.WebViewStringChange
============================================================

when WebViewer1.WebViewStringChange value

  // --------------------------------------------------------
  // 1. Decode the incoming JSON once.
  // --------------------------------------------------------

  set local d to
    call Web1.JsonTextDecode
      text = value

  set local type to
    lookup in pairs
      key = "type"
      dictionary = d

  // --------------------------------------------------------
  // 2. NORMAL STATUS MESSAGE
  //
  // V5.8 JavaScript sends:
  //   {"type":"status","status":"...","detail":"..."}
  //
  // This includes:
  //   READY
  //   WARMUP
  //   ANALYZING
  //   FINALIZING
  //   REPORT
  //   REPORT ERROR
  //   MODEL NOT READY
  //   etc.
  // --------------------------------------------------------

  if type = "status" then

    set local s to
      lookup in pairs
        key = "status"
        dictionary = d

    set local detail to
      lookup in pairs
        key = "detail"
        dictionary = d

    set LabelStatus.Text to
      if
        is empty? detail
      then
        s
      else
        join(
          s,
          " — ",
          detail
        )

  // --------------------------------------------------------
  // 3. ESP32 ↔ APP PARITY RESULT
  //
  // V5.8 JavaScript sends:
  //
  // {"type":"ESP_PARITY_RESULT",
  //  "verdict":"PASS"|"WARN"|"FAIL",
  //  "report":{...}}
  //
  // Detailed parity values are already displayed by the
  // parity card inside WebViewer1.
  //
  // App Inventor only mirrors the final verdict.
  // --------------------------------------------------------
  
  else if type = "ESP_PARITY_RESULT" then

    set global PARITY_VERDICT to
      lookup in pairs
        key = "verdict"
        dictionary = global d

    set global PARITY_READY to true

    set global ESP_ANALYTICS_RECEIVING to true

    set LabelStatus.Text to
      join(
        "ESP32↔APP PARITY ",
        global PARITY_VERDICT
      )

  // --------------------------------------------------------
  // 4. MODEL ERROR
  //
  // V5.8 JavaScript sends:
  // {"type":"model_error","error":"..."}
  // --------------------------------------------------------

  else if type = "model_error" then

    set local err to
      lookup in pairs
        key = "error"
        dictionary = d

    set LabelStatus.Text to
      join(
        "TCN MODEL ERROR — ",
        err
      )

  // --------------------------------------------------------
  // 5. FINALIZATION ERROR
  //
  // V5.8 JavaScript sends:
  // {"type":"finalization_error","error":"..."}
  // --------------------------------------------------------

  else if type = "finalization_error" then

    set local err to
      lookup in pairs
        key = "error"
        dictionary = d

    set LabelStatus.Text to
      join(
        "FINALIZATION ERROR — ",
        err
      )

  // --------------------------------------------------------
  // 6. UNKNOWN / NON-JSON FALLBACK
  //
  // Keep a safe fallback so unexpected debug text is visible.
  // --------------------------------------------------------

  else

    set LabelStatus.Text to value
